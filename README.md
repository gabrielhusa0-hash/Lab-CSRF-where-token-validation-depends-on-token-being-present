## Můj postup (Krok za krokem)

1. **Přihlášení a zadání e-mailu:** Přihlásil jsem se pomocí údajů `wiener` a `peter`. V sekci My Account jsem viděl aktuální e-mail (`wiener@normal-user.net`), který jsem přepsal na `jack@hacker.de` a potvrdil tlačítkem.

# TECHNICKÉ VYSVĚTLENÍ: PROČ TO FUNGOVALO?
Závislost validace na přítomnosti tokenu: Aplikace se sice pokoušela chránit pomocí CSRF tokenu, ale její logika byla chybná. Token kontrolovala pouze v případě, že byl součástí odeslaných dat.

Bypass vynecháním tokenu: Pokud útočník (nebo skript) parametr csrf z požadavku úplně odstranil, server vyhodnotil, že tam žádný token není, kontrolu zcela přeskočil a požadavek přijal jako platný.
